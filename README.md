# Protocol Over Prose

Slides for the 15-minute lightning talk
**"Protocol Over Prose: Engineering Rich Interactivity with A2UI"**

## Run

```bash
npm install
npm run dev          # opens http://localhost:3030
```

Edit `slides.md` — that's the whole deck. Custom visuals live in `components/`.

## Shortcuts (during the talk)

- `←` / `→` / `space` — navigate
- `o` — slide overview grid
- `f` — fullscreen
- `d` — drawing/annotation overlay
- `p` — presenter mode (notes + timer)

## Export

```bash
npm run export       # PDF
npm run build        # static SPA in /dist
```
